# vault-search — Agent Guide

`vault-search` is a thin CLI over an `obsidian-hybrid-search serve` daemon. See [PRODUCT.md](PRODUCT.md) for what it does, [README.md](README.md) for install and usage, and [DEVELOPMENT.md](DEVELOPMENT.md) for build, versioning and release mechanics. Do not restate their content here.

## Git

Commit directly to `main`; do not create a feature branch. This is a solo repo whose releases are tags on `main`, so branch-and-PR adds ceremony without a reviewer.
